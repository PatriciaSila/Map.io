# Wajir County Healthcare Accessibility Web Map

**Interactive GIS web map for visualizing healthcare accessibility across Wajir County, Kenya.**

---

## Overview

Access to healthcare is influenced by the spatial distribution of health facilities, transportation infrastructure, and the geographic distance between the people and available services.

This project develops an interactive web map to visualize the spatial distribution of healthcare facilities and assess geographic accessibility across Wajir County, Kenya.

The project combines spatial analysis in GIS with web-based cartographic visualization to transform geospatial analysis results into an interactive decision-support map.

---

## Study Area

**Wajir County, Kenya**

Wajir County is located in northeastern Kenya and covers a large, predominantly arid area with dispersed settlements and infrastructure.

---

## Data

The analysis incorporates spatial datasets representing:

- Healthcare facilities
  - Main hospitals
  - Dispensaries
  - Nursing homes
- Road infrastructure
  - Class A roads
  - Class B roads
  - Class C roads
  - Other roads
- Administrative boundaries
  - Sub-counties
- Healthcare accessibility analysis results

The healthcare facility data contain attributes such as:

- Facility name
- Facility level
- Ownership
- Facility type
- Sub-county
- Ward
- Geographic coordinates

---

### GIS & Spatial Analysis
- Software: QGIS, ArcGIS, Visual Studio Code
- Accessibility analysis: Raster overlay (population and eucledian/cost distance)
- Cartographic visualization
